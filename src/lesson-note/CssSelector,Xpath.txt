NOTE: ESCAPE DOUBLE QUOTE CHARACTER BY USING \
	e.g: input[placeholder="Enter \"email\""]

CSS Selector:
- tagName: <tagName>
- attribute [attriute="value"]
- tagName + attribute <tagName>[attriute="value"]
- id: #<idValue>
- class: <tagName>.<classValue>
- Wildcard
	+ Start ^: [placeholder^="User"] =>Element has placeholder attribute value starts with User
	+ End $: [placeholder$="name"]
	+ Contains *: [placeholder*="na"]
- child element: parent > child
- Logic OR: cssSelector1, cssSelector2, ... ([name="username"],[name="password"])
- Logic AND: cssSelector1cssSelector2 ([name="username"][placeholder="Username"])

XPATH:
Note: Character * reprensent for any tagName
	eg: //*[@name="username"] =>Element having attribute name with value = username
*Absolute Path: /
	eg: /html/body/div/div/div/div/div/div[2]/h5
*Relative Path: //
	eg: //h5

- Find exactly element position: (xpath)[index]
		eg: (//input)[1]
- tagName + attribute: //<tagName>[@attribute="value"]
- raw text: //<tagName>[text()="value"]
- contains: 
	//<tagName>[contains(text(),"value")]
	//<tagName>[contains(@attribute,"value")]
- starts-with: //<tagName>[starts-with(@attribute, "value")]
- Logic OR: //input[@name="username" or @name="password" and @class]
- Logic AND: //input[@name="username" and @name="password" and @class]
			//input[@name="username"][@name="password"]
- count(): //body/ul/[count(li)>1] =>Return <ul> tag which has more than 1 <li> child tag
- position(): //body/ul/li[position()>1]  =>Return all <li> tag that located at index > 1
